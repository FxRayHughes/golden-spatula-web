## Introduction

**S11 Exalted Finder** is a web version of the S11 Exalted lookup spreadsheet for TFT / JCC Set 11 Inkborn Fables. Pick the Exalted units you see to find the combination and recommended lineups.

## Features

- **Exalted Lookup**: Two units are usually enough to identify the combination.
- **Message Board**: Players leave feedback; admins can reply, feature and delete.
- **Community Submissions**: New combinations and lineups are published after admin review.
- **Multiple Admins**: The owner account is created from install parameters and can add more admins.
